# 질문 5개 생성 규칙

목적은 "브랜드를 몰라도 이 니즈로 검색하면 AI가 뭐라고 답하는지"를 보는 것이다.
그래서 **질문에 자사·경쟁사 브랜드명은 물론 구체적 제품명도 절대 넣지 않는다**
— 둘 다 들어가면 AI가 그걸 중심으로 답해서 자연 노출을 측정할 수 없다.

## 고정 구조 (총 5개)

추천 비교가 이 스킬의 핵심 산출물이라 그 비중을 가장 크게 잡는다. 문제인지
단계는 뺐다 — 원래도 1개뿐이라 신호가 가장 약했던 슬롯이고, 5개로 줄이면서
그 자리를 먼저 덜어냈다.

| 여정 단계 | 개수 | 이 단계가 보는 것 |
|---|---|---|
| Q1 · 해결책 탐색 | 1 | 어떤 종류의 제품·서비스·방법을 후보로 올리는가 |
| Q2~Q4 · 브랜드·제품 추천 | 3 | 실제로 어떤 이름을 추천하는가 |
| Q5 · 비교·선택 | 1 | 후보 간 비교 기준을 뭘로 잡고 누구를 우위에 두는가 |

**지표 분모를 질문 생성 전에 고정한다.** 언급률은 Q1~Q5를 모두 쓰고, 추천률·
추천 SoV·평균 추천순위는 Q2~Q5만 쓴다. Q1에서 추천이 우연히 나와도 질문별
결과에만 표시하고 추천 지표에는 넣지 않는다.

## 작성 기준

- `templates/brand_profile.md`의 "주요 제품·서비스와 타깃 고객" 문구를 그대로
  가져다 쓰지 말고, **그 타깃 고객이 실제로 검색창에 칠 법한 말투**로 바꾼다.
  (예: 브랜드 설명이 "반려동물 영양제"여도 질문은 "강아지가 자꾸 눈물 흘리는데
  뭘 먹여야 하나요" 처럼 증상·상황형으로.)
- 목표 국가·시장·언어에 맞춘다 — 해외 타깃이면 해당 언어로 질문을 만들고, 그 시장의
  검색 습관(예: 미국은 브랜드 비교형이 흔함)을 반영한다.
- 질문 하나당 하나의 니즈만 담는다. 복합 질문은 어느 지점에서 브랜드가 빠졌는지
  판정하기 어렵다.
- 브랜드/제품 카테고리명은 써도 되지만(예: "강아지 유산균") 구체 브랜드명·
  구체 제품명(자사·경쟁사 둘 다)은 금지.

## 대화창에 바로 보여준다 — 파일에 저장하지 않는다

질문 5개를 만들면 파일에 쓰지 않고 **채팅 대화 안에 번호만 매겨서 보여준다.**
여정단계 라벨("(해결책탐색)" 같은)은 내부 분류일 뿐 사용자에게 보일 이유가 없으니
**넣지 않는다.** 사용자가 바로 복사해서 ChatGPT에 붙여넣을 수 있는, 질문만
깔끔하게 있는 형태여야 한다:

```
Q1. ...
Q2. ...
Q3. ...
Q4. ...
Q5. ...
```

ID(Q1~Q5)와 여정단계는 6~8단계에서 계속 같은 걸로 참조해야 하니 — **스킬
자신의 대화 맥락 안에서만** 기억해두고 뒤에서 바꾸지 않는다. 사용자에게 보여줄
땐 번호만, 여정단계는 8단계 리포트 부록에서만 다시 드러난다(거기선 근거자료로서
의미가 있다).
재측정할 땐 8단계 리포트에 남는 질문 목록(부록)을 그대로 다시 쓰면 된다.
