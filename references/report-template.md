# 최종 리포트 구조

제목은 `{이름} ChatGPT GEO 스냅샷 — {측정일}`로 한다. GEO 측정은 질문 5개·단일
시점 결과이고, 사이트 기술 점수는 공개 핵심 페이지 3~5개를 같은 체크리스트로
확인한 별도 결과다. 기술 점수가 실제 ChatGPT 추천을 보장하는 것처럼 표현하지 않는다.

최종 수치와 HTML은 사람이 손으로 다시 계산하지 않고 `report-data.json`을
`scripts/build_report.py`로 렌더링한다. 데이터 구조는 `references/report-data.md`를
따른다.

## 섹션 순서

1. **한계 배너** — 질문 5개, 단일 시점, 반복 측정 없음. 기술 진단은 추천을
   보장하지 않는 별도 결과임을 두 문장으로 분리한다.
2. **상단 요약** — 왼쪽 사이트 기술 점수, 오른쪽 핵심 지표 4개를 2×2로 표시한다.
3. **사이트 기술 진단 상세** — 확인 URL, AI 접근 상태, 기술 완성도, 콘텐츠
   신뢰성, 참고·점수 미포함을 구분한다.
4. **전체 브랜드 비교표** — 자사, 지정 경쟁사, 자동 발견 경쟁사를 모두 표시한다.
   지정 경쟁사가 답변에 없어도 0으로 남긴다.
5. **질문별 결과** — Q1~Q5 질문, 자사 언급 O/X, 자사 추천 O/X, 본문에서 등장한
   경쟁 브랜드를 표시하고 응답 원문을 접어서 제공한다.
6. **답변에서 발견된 경쟁사** — 언급된 질문 수를 막대와 표로 표시한다.
7. **경쟁사가 강한 질문** — Q2~Q5에서 경쟁사는 추천됐지만 자사는 추천되지 않은
   질문만 뽑고, 판단 기준을 함께 밝힌다.
8. **확인된 출처 표기** — 복사본에 보인 URL·칩 라벨만 관찰 목록으로 표시한다.
   비율이나 완전한 집계라고 표현하지 않는다.
9. **관찰 기반 개선 가설** — 기술 상태와 답변 현상을 인과관계로 단정하지 않는다.
   `~일 가능성이 있어 확인이 필요함`처럼 검증할 가설로 쓴다.
10. **우선 개선 과제** — 최대 3개.
11. **재측정 방법** — 개선 반영·재크롤링 시간을 고려해 보통 2~4주 후, 같은
    Q1~Q5를 각각 새 대화에서 다시 실행하도록 안내한다. 변화 보장은 하지 않는다.
12. **한계와 부록** — 표본·변동성 한계와 실제 사용한 질문 5개를 남긴다.

## 핵심 지표

| 지표 | 고정 산식 | 표시 |
|---|---|---|
| 언급률 | Q1~Q5 자사 언급 수 / 5 | `3/5 · 60%` |
| 추천률 | Q2~Q5 자사 추천 수 / 4 | `2/4 · 50%` |
| 추천 SoV | Q2~Q5 자사 추천 수 / 모든 비교 브랜드 추천 수 | `2/6 · 33%` |
| 평균 추천순위 | Q2~Q5의 신뢰 가능한 자사 순위 평균 | `1.5위 (2/2건 순위 확인)` 또는 `-` |

추천 SoV의 모든 비교 브랜드는 자사·지정 경쟁사·자동 발견 경쟁사다. 전체 추천이
0건일 때만 추천 SoV를 `N/A`로 표시한다. 출처는 관찰 목록으로만 남긴다.

## 질문별 판정 표시

- Q1의 추천은 질문별 표에는 O/X로 보여주되 추천 지표에서 제외됐다는 설명을 둔다.
- 추천순위는 명시적 순위나 명확히 정렬된 목록·표에서만 계산한다.
- 실제 매칭된 자사 이름과 근거 문장을 보존한다.
- AI 응답 원문은 `<details>` 안의 `<pre>`에 HTML 이스케이프해서 넣는다. 붙여넣은
  텍스트가 리포트 태그나 스타일로 실행되지 않게 한다.

## 완료 표시와 저장

- 실행 폴더: `geo-test-results/{safe-slug}-{YYYYMMDD-HHMMSS}/`
- 원본 데이터: `report-data.json`
- 검토용 리포트: `report.md` 맨 아래 `<!-- geo-test-run: complete -->`
- 실행 보관용 HTML: `report.html`
- 사용자용 HTML: 가능하면 다운로드 폴더의
  `{safe-slug}_chatgpt_geo_{YYYYMMDD-HHMMSS}.html`

템플릿 파일 존재 여부가 아니라 `report-data.json`의 `status: complete`와 마크다운
완료 표시로 완료 실행을 판단한다.
