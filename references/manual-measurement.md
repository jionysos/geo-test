# ChatGPT 수동 측정 안내

이 스킬은 외부 API를 호출하지 않는다. 질문을 ChatGPT에 직접 넣고 나온 답변을
가져오는 과정만 사용자가 수행하며, 나머지 정리와 계산은 스킬이 맡는다.

## 사용자에게 안내할 내용

1. Q1~Q5를 **각각 새 ChatGPT 대화**에서 원문 그대로 실행한다.
2. 질문과 답변 전체를 이 대화창에 그대로 붙여넣는다. 하나씩 보내도 되고 다섯 개를
   한꺼번에 보내도 된다.
3. 화면에 함께 복사되는 출처 칩·각주가 있으면 그대로 둔다. URL을 따로 찾거나
   출처 칩을 일일이 열 필요는 없다.

사용자에게 파일 작성, 표 채우기, 검색 방식 선택 같은 추가 작업을 시키지 않는다.
어느 질문의 답인지 구분할 수 없을 때만 Q번호를 확인한다.

## 분석할 때의 주의

- 답변 본문과 출처 칩·각주 텍스트를 분리한다.
- 출처에만 나온 이름은 브랜드 언급·추천으로 세지 않는다.
- 복사본에 보이는 출처 라벨이나 URL은 `확인된 출처 표기`에 관찰값으로 남긴다.
- `+1`, `+2`처럼 묶인 출처의 내부 항목은 추측하지 않는다.
- 답변 일부만 붙여넣어 판정 근거가 부족하면 그 질문의 전체 답변만 다시 요청한다.

## 사용자에게 보여줄 마지막 안내 문장

**각 질문을 ChatGPT의 새 대화에서 하나씩 실행하고, 질문과 답변 전체를 그대로 이
채팅창에 붙여넣어 주세요.**
