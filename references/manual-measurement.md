# 수동 측정 안내

이 스킬은 외부 AI API를 호출하지 않는다. **사람이 직접 각 서비스에 질문을 넣고
답변을 가져오는 것이 유일한 데이터 소스다.** 이 문서는 그 과정을 최대한 짧고
실수 없게 만드는 게 목적이다.

## 두 가지 모드 — 다른 걸 보여준다

| 모드 | 뭘 보는가 | 인용률 |
|---|---|---|
| **검색 모드** (기본) | 지금 웹에서 실제로 뭐가 뜨는가 — GEO. 출처 URL이 표시됨 | 계산 가능 |
| **일반 모드** (검색 꺼짐) | 모델이 학습 때부터 우리 브랜드를 원래 알고 있는가 — LLMO. 출처 URL 없음 | N/A |

두 모드를 다 돌리면 **"AI가 아예 모르는 건지 vs 알긴 아는데 검색 결과에서만 안
뜨는 건지"**를 구분할 수 있다. 이 차이는 처방이 다르다 — 일반 모드에서도 언급이
안 되면 브랜드 자체가 안 알려진 것(콘텐츠 노출을 넓혀야 함), 일반 모드에선
언급되는데 검색 모드에서만 안 뜨면 지금 웹에 있는 콘텐츠가 검색에 안 걸리는
것(사이트·콘텐츠 문제, 2단계 기술진단과 연결). 시간이 없으면 검색 모드만 해도
스냅샷은 나온다 — 일반 모드는 선택사항이다.

- 질문마다 **새 대화**에서 실행한다. 같은 대화창에서 이어서 물으면 이전 질문의
  맥락이 다음 답변에 영향을 줘서 독립 측정이 안 된다.
- 질문 문구는 `templates/questions.md`에 저장된 그대로, 토씨 하나 안 바꾸고 붙여넣는다.

## 절차 (질문 10개 × 선택한 모델 수 만큼 반복)

1. 새 대화 시작
2. `templates/questions.md`에서 질문 ID 하나를 그대로 복사해 입력
3. 답변이 끝날 때까지 기다린다 (검색 중이면 완료까지)
4. 답변 **전체 텍스트**를 복사 (일부만 복사하면 뒤쪽에 나온 언급을 놓친다)
5. 화면에 표시된 출처/인용 URL이 있으면 전부 복사 (각주 링크, 하단 출처 목록 등)
6. `templates/responses.md`에 아래 형식으로 붙여넣기

```
### Q1 — ChatGPT (검색 모드)

**질문:** (그대로)

**답변 전문:**
(붙여넣기)

**표시된 출처 URL:**
- ...
- ...
```

일반 모드로 추가 실행할 땐 헤더만 `### Q1 — ChatGPT (일반 모드)`로 바꾸고,
출처 URL 항목은 비워두거나 지운다(애초에 없다).

## 선택: 추가 모델 · 일반 모드

Gemini·Perplexity·네이버(Cue: 등)도 원하면 같은 형식으로 추가한다. 모델마다
섹션을 나눠서(`### Q1 — Perplexity`) 같은 질문 ID 아래 모아두면 6단계 분석이
쉬워진다. ChatGPT 일반 모드(검색 꺼짐)를 추가해서 LLMO 신호를 같이 보고 싶으면
`### Q1 — ChatGPT (일반 모드)`로 똑같이 추가한다. 뭘 추가하든 총 실행 횟수가
늘어난다는 것만 미리 안내한다 — 무리해서 다 채우지 않아도 된다, 검색 모드
1개만으로도 스냅샷은 나온다.

## 흔한 실수

- 검색 꺼진 상태로 다 돌리고 나서 "인용률이 왜 다 0%냐"고 묻는 경우 → 애초에 N/A
- 질문을 대화 맥락 안에서 이어 물어서 브랜드가 먼저 언급된 경우 → 새 대화로 다시
- 답변 앞부분만 복사해서 뒤에 나온 경쟁사 언급을 놓치는 경우 → 전체 복사 원칙
- 오늘 측정한 걸 다음 주 결과와 섞어서 비교하는 경우 → 측정 시점(날짜)을 항상
  같이 기록한다
