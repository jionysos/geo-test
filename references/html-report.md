# HTML 리포트 생성 규칙

HTML을 대화형 모델이 매번 직접 조립하지 않는다. `references/report-data.md` 형식의
`report-data.json`을 만든 뒤 아래 명령으로 Markdown과 HTML을 함께 생성한다.

```bash
python3 /path/to/geo-test/scripts/build_report.py \
  --input geo-test-results/{run}/report-data.json \
  --run-dir geo-test-results/{run} \
  --download-copy ~/Downloads/{safe-slug}_chatgpt_geo_{timestamp}.html
```

다운로드 폴더 쓰기 권한이 필요하면 사용자에게 승인을 요청한다. 사용할 수 없거나
거절되면 `--download-copy`만 빼고 실행해 실행 폴더의 `report.html` 경로를 안내한다.

## 렌더러가 보장하는 것

- 외부 CDN·JavaScript 없이 한 파일로 열리는 정적 HTML
- 상단 `2fr 3fr` 요약 레이아웃: 왼쪽 기술 점수, 오른쪽 핵심 지표 4개
- 760px 이하에서는 한 열로 전환하고 넓은 표는 가로 스크롤
- 기술 상세 표의 항목·상태·근거 너비를 `26% / 14% / 나머지`로 통일
- 사이트 기술 게이지의 구간을 점수 밴드와 일치시킴
  - 시급 0~49
  - 보완 필요 50~69
  - 양호 70~89
  - 우수 90~100
- 언급률·추천률·추천 SoV·평균 추천순위 4개를 2×2 카드로 표시
- 지정 경쟁사와 자동 발견 경쟁사를 한 비교표에 포함
- 질문별 O/X, 본문 등장 브랜드, 접어서 보는 답변 원문
- 경쟁사 등장 답변 수를 최댓값 기준 가로 막대로 표시
- Q2~Q5에서 경쟁사는 추천됐지만 자사는 추천되지 않은 질문을 별도 표시
- 확인된 출처 표기를 비율이 아닌 관찰 목록으로 표시
- 모든 브랜드명·질문·답변·근거·URL을 HTML 이스케이프해 붙여넣은 내용이 태그나
  스크립트로 실행되지 않게 함

## 게이지 구현 확인

점수 바늘은 `-90 + 점수 × 1.8`도로 회전한다. 반원의 구간 경계 좌표는 다음과 같다.

```text
0점   (20, 100)
50점  (100, 20)
70점  (147.02, 35.28)
90점  (176.08, 75.28)
100점 (180, 100)
```

색상 호는 0~50, 50~70, 70~90, 90~100 범위를 위 좌표로 그린다. 등급 표시의 정수
경계는 0~49, 50~69, 70~89, 90~100이다.

## 재렌더링

리포트 디자인만 바꿀 때는 질문 생성·측정·판정을 다시 하지 않는다. 기존 실행 폴더의
`report-data.json`을 최신 `build_report.py`로 다시 렌더링한다. 데이터 내용이
바뀌었을 때만 해당 판정을 수정한 뒤 재실행한다.
