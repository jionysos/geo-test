# 판정·지표 계산 규칙

이 문서는 사람이 답변을 판정할 때와 `scripts/build_report.py`가 지표를 계산할 때
공통으로 쓰는 기준이다. 질문 ID와 분모는 실행 후 임의로 바꾸지 않는다.

## 1. 답변 본문과 출처 표시를 먼저 분리한다

- **답변 본문**: ChatGPT가 사용자에게 설명·비교·추천한 문장과 표·목록.
- **출처 표시**: 답변 주변의 출처 칩, 각주, 도메인 라벨, `+N` 표시.
- 출처 표시에만 나온 이름은 언급·추천으로 세지 않는다. `sources`에 관찰값으로만
  기록한다.
- 유통사·언론사·콘텐츠 제공자는 답변 본문에서 실제 제품·서비스 선택지로 제시되지
  않았다면 경쟁사로 넣지 않는다.

이 분리가 필요한 이유는 ChatGPT의 출처 칩 이름이 답변 복사본에 섞일 수 있기
때문이다. 출처 제공자를 경쟁 브랜드로 잘못 세면 언급률과 추천 SoV가 모두 왜곡된다.

## 2. 자사 범위와 표기 매칭

- 회사·브랜드·제품은 **실제로 같은 회사에 귀속된 것으로 확인된 이름만** 하나의
  자사 생태계로 합친다.
- 핵심 이름, 공식 영문명, 띄어쓰기 변형, 확인된 제품·라인명 중 하나가 답변 본문에
  나오면 자사 언급으로 센다.
- 유통사·제휴사·경쟁 제품은 자사에 합치지 않는다.
- 경쟁사도 같은 원칙을 적용한다. 제품·별칭·도메인 소유관계를 모델 기억만으로
  채우지 말고 공식 사이트 등 확인 가능한 근거를 사용한다.
- 판정에는 실제로 매칭된 이름을 남긴다. 예: `제품명 'OO관절엔'으로 자사 매칭`.
- 일반명사와 겹치거나 소유관계가 불명확하면 임의로 합치지 않는다.

한 답변에서 같은 생태계의 이름이 여러 번 또는 여러 형태로 나와도 해당 질문에서는
언급 1회, 추천 1회까지만 센다.

## 3. 언급과 추천

- **언급**: 답변 본문에 확인된 회사·브랜드·제품 이름이 등장한다. 중립적 비교나
  단순 나열도 언급이다.
- **추천**: 사용자의 선택지로 실제 권유하거나, 추천 목록·비교 결과에서 적합한
  후보로 제시한다.
- 단순 예시, 배경 설명, 판매처·출처 표기, 부정적 경고, 비교 대상으로만 나온 이름은
  추천이 아니다.
- 각 O/X 판정에는 검증 가능한 근거 문장을 남긴다.

어떤 브랜드가 5개 답변 전체에서 0회면 관련 이름을 원문에서 한 번 더 확인한 뒤
0으로 확정한다. 확인되지 않은 표기 변형을 추측해서 결과를 바꾸지는 않는다.

## 4. 질문별 지표 포함 범위

| ID | 용도 | 언급률 | 추천률·추천 SoV·평균 추천순위 |
|---|---|---:|---:|
| Q1 | 해결책 탐색 | 포함 | 제외 |
| Q2 | 브랜드·제품 추천 | 포함 | 포함 |
| Q3 | 브랜드·제품 추천 | 포함 | 포함 |
| Q4 | 브랜드·제품 추천 | 포함 | 포함 |
| Q5 | 비교·선택 | 포함 | 포함 |

Q1에서 우연히 추천이 나와도 질문별 결과에는 O로 표시하되 추천 지표에는 넣지 않는다.
실제 답변을 본 뒤 유리한 질문만 고르는 것을 막기 위한 고정 규칙이다.

## 5. 비교 브랜드 집합

추천 SoV와 전체 비교표에는 다음을 모두 포함한다.

1. 자사
2. 사용자가 미리 지정한 경쟁사
3. 답변 본문에서 새로 발견된 실제 경쟁 브랜드·제품

지정 경쟁사가 답변에 한 번도 없어도 표에서 빼지 않고 0으로 남긴다. 자동 발견
경쟁사도 지정 경쟁사와 같은 판정 기준으로 언급·추천·순위를 기록한다. 지정 여부는
출처 설명용 속성일 뿐, 계산 포함 여부를 바꾸지 않는다.

## 6. 추천순위

다음 근거가 있을 때만 숫자 순위를 기록한다.

- 답변에 `1순위`, `2위`처럼 명시적 숫자가 있음: `explicit`
- 번호가 매겨진 추천 목록처럼 순서가 추천 우선순위임이 명확함: `ordered-list`
- 비교표가 순위 또는 추천 우선순위를 명확히 나타냄: `comparison-table`

일반 설명문에서 먼저 등장했다는 이유만으로 추천순위를 만들지 않는다. 명시적 순위나
명확히 정렬된 추천 목록이 없으면 추천 O여도 순위는 비워둔다. 평균 추천순위에는
신뢰 가능한 숫자만 포함하고, 리포트에는 `1.5위 (2/3건 순위 확인)`처럼 순위 확인
건수를 함께 보여준다. 확인 가능한 순위가 0건이면 `-`로 표시한다.

## 7. 지표 공식

- **언급률** = Q1~Q5에서 해당 브랜드가 언급된 답변 수 / 5
- **추천률** = Q2~Q5에서 해당 브랜드가 추천된 답변 수 / 4
- **추천 SoV** = Q2~Q5 자사 추천 수 / Q2~Q5의 자사·지정 경쟁사·자동 발견
  경쟁사 전체 추천 수
- **평균 추천순위** = Q2~Q5에서 신뢰 가능한 자사 추천순위 합 / 순위 확인 건수

한 질문에서 브랜드별 최대 1회이므로 추천 SoV의 단위는 **브랜드-질문 추천 사건**이다.
전체 추천 수가 0이면 추천 SoV는 `N/A`, 자사만 추천됐다면 `100%`다. 평균
추천순위는 순위 확인 건수가 0일 때 `-`다.

핵심 지표는 **언급률·추천률·추천 SoV·평균 추천순위** 4개만 쓴다. 출처는 관찰
목록으로만 남기고 비율 지표로 만들지 않는다.

## 8. 출처 관찰

출처 URL·도메인·칩 라벨이 복사본에 보이면 `확인된 출처 표기`에 그대로 남긴다.
다만 `+N` 안의 출처는 복사본만으로 알 수 없으므로 출처 비율이나 순위를 만들지
않는다. 이 목록은 완전한 집계가 아니라 화면에 남은 관찰 기록이다.

## 집계 예시

| 브랜드 | 구분 | 언급률 | 추천률 | 추천 SoV | 평균 추천순위 |
|---|---|---|---|---|---|
| 자사 | 자사 | 2/5 | 1/4 | 17% | 2.0위 (1/1건 순위 확인) |
| 경쟁사A | 지정 | 4/5 | 3/4 | 50% | 1.3위 (3/3건 순위 확인) |
| 경쟁사B | 자동 발견 | 3/5 | 2/4 | 33% | - |
| 경쟁사C | 지정 | 0/5 | 0/4 | 0% | - |
