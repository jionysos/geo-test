# geo-snapshot

**브랜드가 ChatGPT·Perplexity·네이버 AI 답변에 얼마나, 경쟁사 대비 어떻게
나오는지 확인하는 무료 Claude Code 스킬.**

기술적 SEO 진단만 하는 도구는 많고, "실제 AI 답변에서 우리 브랜드와 경쟁사가
어떻게 다르게 나오는지"를 직접 비교해주는 무료 도구는 별로 없어서 만들었습니다.

## 뭐가 다른가

- **사이트 진단으로 끝나지 않는다.** robots.txt·sitemap·구조화 데이터 같은
  기술 진단은 하되, 그건 1부일 뿐이고 핵심은 실제 AI 답변 비교다.
- **경쟁사와 나란히 비교한다.** 자사 인용 O/X만 보는 게 아니라, 지정한 경쟁
  브랜드까지 같은 질문·같은 기준으로 언급률·추천률·인용률·SoV를 비교한다.
- **언급과 추천을 구분한다.** 이름만 스쳐 지나간 것과 실제로 권유받은 것은
  다른 신호다. 이 둘을 같은 숫자로 뭉개지 않는다.
- **질문이 여정 단계별 고정 구조다.** 자유형으로 아무 질문이나 만들지 않고,
  문제인지 1·해결책탐색 2·브랜드제품추천 6·비교선택 1로 고정해(추천 비교가
  핵심이라 비중을 가장 크게 잡는다) 재측정 때도 같은 기준으로 비교할 수 있게 한다.
- **결과가 표준 파일로 남는다.** 질문지·원본 답변·판정 근거·최종 리포트가
  전부 파일로 남아서 나중에 재검증하거나 재측정과 비교할 수 있다.

## 이 스킬이 하지 않는 것 (의도적으로)

외부 AI API 호출, 자동 반복 실행, 스케줄러, 다중 실행 변동성 보정, 대시보드,
수백 개 질문 관리, 업종 벤치마크, 자동 CMS 배포, 텔레메트리, 사용자 데이터
수집, 영업·상담 유도. 전부 무료 범위 밖으로 남겨뒀습니다 — 이유는
[SKILL.md](./SKILL.md)의 "범위 밖" 섹션 참고.

측정 자체도 API로 자동화하지 않습니다. **질문 10개를 사람이 직접 ChatGPT 등에
넣고 답변을 가져오면, 그 답변을 분석·비교·집계하는 것까지가 이 스킬의 역할**
입니다. API 키가 없어도 누구나 바로 쓸 수 있게 하기 위한 의도적인 선택입니다.

## 설치

```bash
# 프로젝트 스킬로 (해당 프로젝트에서만)
git clone https://github.com/<your-org>/geo-snapshot.git .claude/skills/geo-snapshot

# 또는 개인 스킬로 (모든 프로젝트에서)
git clone https://github.com/<your-org>/geo-snapshot.git ~/.claude/skills/geo-snapshot
```

Claude Code에서:

```
/geo-snapshot 우리 브랜드 AI 가시성 진단해줘
```

## 사용 흐름

1. 대화로 브랜드명·설명·도메인을 알려준다 — 양식을 채우는 게 아니라 편하게
   말하면 스킬이 정리한다. 경쟁사는 **이름만** 나열하면 되고(없으면 없다고
   해도 됨), 표기 변형·도메인은 스킬이 먼저 제안하고 확인만 받는다
2. 스킬이 사이트를 기술 진단하고 우선순위를 보고한다 (승인 후에만 수정)
3. 스킬이 브랜드명 없는 질문 10개를 만든다
4. 그 질문들을 ChatGPT(기본) 등에 그냥 물어보고 답변을 붙여넣는다 — 검색모드를
   미리 고를 필요 없이, 출처 URL이 붙었는지로 스킬이 알아서 판별한다
5. 스킬이 자사·경쟁사의 언급률·추천률·인용률·SoV를 계산해 리포트로 정리한다

전체 절차는 [SKILL.md](./SKILL.md), 단계별 세부 규칙은 [references/](./references)에
있습니다.

## 결과물

결과는 "AI 가시성 점수" 같은 과장된 단일 점수가 아니라 **ChatGPT GEO 스냅샷**
(모델 1개 측정 시) 또는 **멀티모델 GEO 스냅샷**(2개 이상)으로 부릅니다. 질문
10개·단일 시점 기준의 스냅샷이라는 한계를 리포트에 항상 명시합니다.
