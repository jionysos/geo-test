# geo-test

**브랜드가 ChatGPT·Perplexity·네이버 AI 답변에 얼마나, 경쟁사 대비 어떻게
나오는지 확인하는 무료 스킬.** SKILL.md 표준을 쓰는 Claude Code·Codex CLI에서
동일하게 작동합니다.

기술적 SEO 진단만 하는 도구는 많고, "실제 AI 답변에서 우리 브랜드와 경쟁사가
어떻게 다르게 나오는지"를 직접 비교해주는 무료 도구는 별로 없어서 만들었습니다.

## 뭐가 다른가

- **사이트 진단으로 끝나지 않는다.** robots.txt·sitemap·구조화 데이터 같은
  기술 진단은 하되, 그건 1부일 뿐이고 핵심은 실제 AI 답변 비교다.
- **경쟁사와 나란히 비교한다.** 자사 인용 O/X만 보는 게 아니라, 지정한 경쟁
  브랜드까지 같은 질문·같은 기준으로 언급률·추천률·SoV를 비교한다.
- **언급과 추천을 구분한다.** 이름만 스쳐 지나간 것과 실제로 권유받은 것은
  다른 신호다. 이 둘을 같은 숫자로 뭉개지 않는다.
- **질문이 여정 단계별 고정 구조다.** 자유형으로 아무 질문이나 만들지 않고,
  해결책탐색 1·브랜드제품추천 3·비교선택 1로 고정해(추천 비교가 핵심이라
  비중을 가장 크게 잡는다) 재측정 때도 같은 기준으로 비교할 수 있게 한다.
- **대화창 안에서 다 끝난다.** 질문도 채팅에 바로 보여주고, 답변도 채팅에
  그대로 붙여넣으면 된다 — 파일 왔다갔다 하는 절차 없음. 최종 리포트 하나에
  질문 목록(부록)·판정 근거·지표가 다 남아서 재측정 때 그대로 다시 쓸 수 있다.
- **기술 진단도 숫자 하나로 요약된다.** robots.txt·구조화 데이터 같은 개별
  배지 말고도, 100점 만점 점수(필수 60·권장 40 비중)로 전체 수준을 바로
  가늠할 수 있다.
- **결과가 시각적인 HTML로도 나온다.** 마크다운 리포트뿐 아니라 게이지 차트·
  표·카드로 정리된 정적 HTML 한 장을 같이 만든다. 외부 서버·CDN 없이 로컬
  파일 그대로 브라우저로 열면 된다.

## 이 스킬이 하지 않는 것 (의도적으로)

외부 AI API 호출, 자동 반복 실행, 스케줄러, 다중 실행 변동성 보정, 대시보드,
수백 개 질문 관리, 업종 벤치마크, 자동 CMS 배포, 텔레메트리, 사용자 데이터
수집, 영업·상담 유도. 전부 무료 범위 밖으로 남겨뒀습니다 — 이유는
[SKILL.md](./SKILL.md)의 "범위 밖" 섹션 참고.

측정 자체도 API로 자동화하지 않습니다. **질문 5개를 사람이 직접 ChatGPT 등에
넣고 답변을 가져오면, 그 답변을 분석·비교·집계하는 것까지가 이 스킬의 역할**
입니다. API 키가 없어도 누구나 바로 쓸 수 있게 하기 위한 의도적인 선택입니다.

## 사용 흐름

1. 대화로 이름·설명·홈페이지를 알려준다 — 양식을 채우는 게 아니라 편하게
   말하면 스킬이 정리한다. 경쟁사는 **이름만** 나열하면 되고(없으면 없다고
   해도 됨), 관련 표기·도메인은 스킬이 먼저 제안하고 확인만 받는다
2. 스킬이 사이트를 기술 진단하고 우선순위를 보고한다 (승인 후에만 수정)
3. 스킬이 브랜드명 없는 질문 5개를 만들어 **채팅에 바로 보여준다**
4. 그 질문들을 ChatGPT(기본) 등에 새 대화로 그냥 물어보고, 나온 답변을 **이
   채팅창에 원문 그대로 붙여넣는다** — 검색모드를 미리 고를 필요도, 출처 URL을
   따로 골라낼 필요도 없다, 원문에 있는 그대로 스킬이 알아서 판별한다
5. 스킬이 자사·경쟁사의 언급률·추천률·SoV를 계산해 리포트로 정리한다

전체 절차는 [SKILL.md](./SKILL.md), 단계별 세부 규칙은 [references/](./references)에
있습니다.

## 결과물

결과는 "AI 가시성 점수" 같은 과장된 단일 점수가 아니라 **ChatGPT GEO 스냅샷**
(모델 1개 측정 시) 또는 **멀티모델 GEO 스냅샷**(2개 이상)으로 부릅니다. 질문
5개·단일 시점 기준의 스냅샷이라는 한계를 리포트에 항상 명시합니다.

## 구조

```
SKILL.md                        ← 에이전트 운영 절차 (정보수집→진단→질문→측정→분석→리포트)
references/
  tech-audit.md                 ← 테크니컬 진단 체크리스트(필수/권장/참고) + 100점 점수 공식
  question-generation.md        ← 여정 단계별 비브랜드 질문 5개 생성 규칙
  manual-measurement.md         ← 사용자가 직접 측정하는 절차 안내
  scoring.md                    ← 언급/추천 판정 기준 + 지표 공식
  report-template.md            ← 최종 리포트 구조 (마크다운)
  html-report.md                ← 같은 내용을 시각적 HTML로 렌더링하는 방법
templates/
  brand_profile.md              ← 1단계 입력값 (스킬이 대화 내용을 정리해 저장)
  report.md                     ← 8단계 최종 산출물, 마크다운 (질문 목록도 부록으로 포함)
  report.html                   ← 8단계 최종 산출물, 시각화 HTML
```

질문 생성(4단계)과 답변 수집(5단계)은 파일을 거치지 않고 전부 채팅 대화 안에서
끝납니다 — 그래서 그 사이엔 템플릿 파일이 없습니다.
